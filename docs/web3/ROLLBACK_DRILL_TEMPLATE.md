## 演练步骤

### 前置检查

- [ ] 确认当前版本

  ```bash
  openclaw --version
  ```

- [ ] 记录当前状态

  ```bash
  openclaw web3 status --json > /tmp/pre-drill-status.json
  openclaw market status --json > /tmp/pre-drill-market.json
  openclaw wallet balance --json > /tmp/pre-drill-balance.json
  ```

- [ ] 确认回滚版本存在
  ```bash
  npm view openclaw@<version> version
  ```

### 执行回滚

- [ ] 执行回滚脚本

  ```bash
  scripts/rollback-web3-market.sh <version>
  ```

- [ ] 记录输出日志
  - 日志文件：[日志路径]

### 后置验证

- [ ] 验证 Gateway 启动

  ```bash
  pgrep -f openclaw-gateway
  curl http://localhost:18789/health
  ```

- [ ] 验证 web3 状态

  ```bash
  openclaw web3 status
  ```

- [ ] 验证市场状态

  ```bash
  openclaw market status
  ```

- [ ] 验证钱包余额

  ```bash
  openclaw wallet balance
  ```

- [ ] 验证历史数据
  ```bash
  openclaw market order list --limit 5
  openclaw market ledger list --limit 5
  ```
