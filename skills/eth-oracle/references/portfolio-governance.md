# Portfolio Governance

本文件规定 `eth-oracle` 如何把分析结果转化为组合治理语言。

## 1. 组合立场枚举

| Stance               | 含义                     | 默认动作         |
| -------------------- | ------------------------ | ---------------- |
| `risk_on`            | 宏观与市场共振偏强       | 允许主动增配     |
| `selective_risk_on`  | 机会存在，但不宜全局进攻 | 只做高质量标的   |
| `neutral`            | 证据不够集中             | 低动作，等确认   |
| `selective_risk_off` | 风险在抬升               | 降低弹性仓位     |
| `risk_off`           | 防守优先                 | 减仓、对冲、等待 |

## 2. 仓位边界

- 单一仓位上限：**25%**
- 若置信度仅为 `low`，建议仓位不超过上限的 40%
- 若进入事件窗口（FOMC、CPI、重大监管裁决），默认先降风险再谈加仓

## 3. Veto 条件

以下任一情况成立，默认触发 `veto`：

1. Tier 1 稳定币重大脱锚
2. 美国 / 欧盟主要监管禁令直接打击核心资产流动性
3. 交易基础设施或主要托管/交易所发生系统性故障
4. 关键 thesis 被官方文件直接证伪

Veto 一旦触发：

- 不再沿用原始乐观结论
- 组合立场至少降至 `risk_off`
- 输出必须写清 `veto_reason`

## 4. 事件驱动降仓

| 事件                        | 默认动作                    |
| --------------------------- | --------------------------- |
| FOMC / CPI 前 48h           | 风险仓位减半                |
| 重大监管裁决前              | 杠杆归零，净敞口下调        |
| 地缘冲突突然升级            | 优先降 beta，再判断是否错杀 |
| 支付 / 稳定币叙事被官方修正 | 立即重算 thesis 权重        |

## 5. 复核节奏

| 场景                 | 复核频率       |
| -------------------- | -------------- |
| 高波动 / 事件窗口    | `24h`          |
| 明显趋势但无重大事件 | `72h`          |
| 中长期 thesis 跟踪   | `7d`           |
| 重大突发             | `event-driven` |

## 6. 输出模板要求

每次治理输出至少包含：

- `stance`
- `recommended_position_size_pct`
- `max_position_pct`
- `risk_triggers`
- `invalidation_conditions`
- `review_cadence`

## 7. 治理哲学

最好的判断，不是把仓位打满；
而是在对的时候敢配，在错的时候退得快，在不清楚的时候保持克制。
