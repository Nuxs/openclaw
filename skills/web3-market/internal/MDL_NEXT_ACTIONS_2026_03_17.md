- P0: 支付失败/资金风险 → 5 分钟响应

### 3.1 重试预算统一

**执行步骤**：

1. 搜索所有重试相关配置
2. 统一到 `Web3PluginConfig.retry.maxRetries`
3. 更新所有调用点
4. 补充测试验证

### 3.2 幂等冲突治理

**问题**：幂等键冲突时的响应不明确。

**解决方案**：

| 场景                            | 响应策略     | HTTP 状态码  |
| ------------------------------- | ------------ | ------------ |
| 相同请求（idempotencyKey 一致） | 返回缓存结果 | 200          |
| 不同请求（idempotencyKey 冲突） | 拒绝 + 告警  | 409 Conflict |
| 审计需求                        | 记录冲突日志 | -            |

**执行步骤**：

1. 在 `market-core` 增加 `IdempotencyConflictHandler`
2. 区分"相同请求"和"冲突请求"
3. 补充审计日志
4. 补充告警触发
